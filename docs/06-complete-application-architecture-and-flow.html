Single Source of Truth

The ProductMasters database table is the absolute source of truth. Any product created or edited in the Admin Drawer is immediately visible on the public website with complete specs.

Admin Provided Images Only

Product imagery displays either the admin-specified ImageUrl or streams directly from uploaded image attachments via /api/v1/public/products/{id}/image.

Zero Flicker Public Experience

The public catalog initializes immediately with the 20 core components and seamlessly merges live updates from the backend without UI disruption.

Summary of foundational platform endpoints and WebSocket hubs.
Method Endpoint Access Description
GET /api/v1/public/products Public / Anonymous Returns active Product Master catalog items with categories and images.
GET /api/v1/public/products/{id}/image Public / Anonymous Streams uploaded product attachment image binary with caching.
POST /api/v1/public/enquiries Public (Rate-Limited) Submits RFQ inquiry with honeypot bot defense.
GET / POST /api/v1/admin/product-master Admin / Engineer Full CRUD, duplicate, archive, and CAD attachment management for products.
GET / PUT /api/v1/admin/orders/{id}/stage Admin / Engineer Advances order across the 25-stage manufacturing Kanban state machine.
WSS /hubs/notifications Authenticated Real-time SignalR WebSocket hub for order milestones, quotes, and alerts.
